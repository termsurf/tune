# The Last Word

**Every one of these 132 kinds needs a three letter Tune word.**

They are the final concept in a compound chain, which makes them among
the most used words the language will have: `discuss` plus `result` is
`discussion`, and `result` will appear in thousands of such chains. A
word used inside other words has to be short.

[`kind.csv`](kind.csv) is the list with what each one currently holds.

| | |
| ---: | :--- |
| 132 | kinds, in fifteen groups |
| 57 | have a word |
| **43** | **are three letters, as they must be** |
| 14 | have a word that is not three letters |
| **75** | **have no word at all** |

Together with the 125 open concepts in [`must.md`](must.md) that is
**200 wanting a `CVC`, against 376 free**, so the whole of both lists
fits with 176 to spare.

Carried over from `note/library/tune/last-word.md`, which is the
original and holds the reasoning below unchanged.

## What it is

What the final concept in a chain can be, the complete set, and how to
decide which one a given English word is actually using.

Refines the nominalizer section of
[`english-base-concepts.md`](english-base-concepts.md), which listed 17
of these. Every one is a single word, because a phrase in the last slot
is a concept nobody has named yet, and an unnamed concept cannot be
composed with.

**The inventory is now data, not prose.**
[`concept/kind.csv`](concept/kind.csv) carries **132 kinds in fifteen
groups**, each with a test sentence and examples, and
[`concept/readme.md`](concept/readme.md) is how it joins the root list
and the pair list. This note is the reasoning: the five questions, the
diagnostics, and the worked breakdown of every common English ending.
The first pass below found 42, and working through the endings and the
living-thing vocabulary found the rest.

## The problem

`discussion` is one English word carrying five different concepts.

```
the discussion lasted three hours        process
there was a discussion last night        event
the discussion produced nothing          result
his discussion of Kant is confused       content
the discussions were filed               record
```

English writes all five as `discuss` plus `-ion` and leaves the reader
to work out which. That is the collapse the last word exists to undo,
and picking one of the five and calling it "the" meaning is the same
mistake in miniature.

The derived catalogue in [`derived/`](derived/readme.md) currently
records `discussion` as `discuss + result` and nothing else, because it
is driven by morphology and English morphology cannot tell these apart.
**Only 89 of its 43,026 rows carry more than one reading.** The true
figure is closer to half.

## The claim

**The last word is not a suffix. It is the answer to a question about
the base, and there are five questions.**

```
1  PHASE     where on the action's arc does this point?
2  ROLE      which participant in the action is this?
3  QUALITY   which property of the thing is this?
4  BODY      which collective or field is this?
5  FRAME     at what remove from the thing is this?
```

Each question has a closed answer set. A chain ends with exactly one
answer, and naming it is the whole job of the last word.

## Question one: PHASE

An action has an arc. It can be pointed at, entered, carried on, ended,
and it leaves things behind. Each point on that arc is a different
concept, and English has no way to tell them apart.

| answer | what it names | the test it passes |
| :--- | :--- | :--- |
| `act` | the bare doing, no bounds in view | "the X of it by them" |
| `process` | the doing unfolding through stages | "the X took three hours" |
| `event` | one bounded countable occurrence | "an X happened" |
| `result` | the state of affairs it leaves | "the X was total" |
| `product` | the made object it leaves | "the X is on the table" |
| `state` | the condition of being in or after it | "the X lasted" |
| `attempt` | the trying, success not implied | "the X failed" |
| `habit` | the repeated doing as a disposition | "he has a X for it" |
| `start` | its beginning | "at the X of it" |
| `finish` | its ending | "at the X of it" |
| `chance` | the opportunity for it | "he got his X" |

**`result` and `product` are not the same.** A result is any outcome, a
product is a made object. `destruction` leaves a result and no product.
`translation` leaves both, and they are different things: the fact that
it was translated, and the text.

```
act        the building of the wall, the reading of the will
process    construction, digestion, negotiation, erosion
event      an explosion, a wedding, an eclipse, a collision
result     the destruction, the connection, the improvement
product    a painting, a building, a translation, an invention
state      sleep, ownership, imprisonment, bankruptcy
attempt    a bid, a try, an application, an approach
habit      a tendency, a leaning, a pull, a weakness
start      the outbreak, the onset, the launch, the opening
finish     the close, the conclusion, the expiry, the finale
chance     an opening, a shot, an opportunity, an appointment
```

## Question two: ROLE

Once the action is fixed, any participant in it can be named, and the
same ending names several of them.

| answer | what it names | the test it passes |
| :--- | :--- | :--- |
| `agent` | one who does it | "the X did it" |
| `target` | one it is done to | "the X was affected" |
| `recipient` | one who receives it | "the X got it" |
| `tool` | what it is done with | "with a X" |
| `method` | how it is done | "by X" |
| `place` | where it is done | "at the X" |
| `time` | when it is done | "during the X" |
| `source` | what it comes from | "out of the X" |
| `goal` | what it aims at | "toward the X" |
| `content` | what it conveys | "the X said that" |
| `measure` | how much of it | "a X of three" |
| `fee` | what is paid for it | "he paid the X" |
| `record` | the document of it | "he filed the X" |
| `cause` | what brings it about | "the X of it was heat" |

```
agent      painter, driver, editor, inspector
target     employee, trainee, broiler, keeper
recipient  addressee, payee, grantee, referee
tool       opener, printer, cutter, detector
method     approach, treatment, procedure, operation
place      bakery, residence, settlement, nursery
time       departure, appointment, harvest, shift
source     feeder, spring, origin, wellspring
goal       destination, target, aim, objective
content    announcement, statement, reading, passage
measure    mileage, coverage, output, dosage
fee        postage, rental, tuition, fare
record     agreement, judgment, receipt, certificate
cause      trigger, driver, factor, agent
```

**`agent` and `tool` are the same ending in English.** `printer` is both
a person and a machine, `cleaner` is a person, a machine and a fluid.
Nothing in the word says which.

## Question three: QUALITY

Asked of a feature rather than an action.

| answer | what it names | the test it passes |
| :--- | :--- | :--- |
| `nature` | the property as such, uncountable | "the X of it" |
| `degree` | how much of the property | "a high X" |
| `instance` | one bearer of the property | "a X", plural |
| `ability` | the capacity for it | "he has X" |
| `tendency` | the leaning toward it | "a X to do it" |

```
nature     kindness, density, warmth, clarity
degree     intensity, severity, magnitude, depth
instance   a curiosity, a necessity, a cruelty, an oddity
ability    judgment, craftsmanship, eyesight, stamina
tendency   irritability, volatility, fragility, proneness
```

**`nature` and `instance` are the same ending.** `curiosity` is both the
property of being curious and an odd object on a shelf. `cruelty` is
both the trait and a particular cruel act.

## Question four: BODY

Asked of a thing, and naming something collective built out of it.

| answer | what it names | the test it passes |
| :--- | :--- | :--- |
| `practice` | the doing of it as a discipline | "he studies X" |
| `study` | the science of it | "X is a science" |
| `society` | the body of people | "the X voted" |
| `domain` | the field or territory | "in the X" |
| `language` | the way of speaking | "he speaks X" |
| `collection` | the set of them | "a X of them" |
| `system` | them arranged and working | "the X works" |
| `period` | the span of being it | "during his X" |
| `office` | the position held | "he held the X" |

```
practice   surgery, tourism, robbery, carpentry
study      biology, geology, phonology, archaeology
society    the government, the administration, the membership
domain     neighborhood, jurisdiction, administration, industry
language   japanese, legalese, journalese, cantonese
collection machinery, equipment, furniture, jewelry
system     the bus service, the writing, the network, the grid
period     childhood, apprenticeship, administration, reign
office     the presidency, the championship, the chair, the seat
```

## Question five: FRAME

The remove at which the concept stands from the thing.

| answer | what it names | the test it passes |
| :--- | :--- | :--- |
| `model` | the abstract shape of it | "a X of the X" |
| `token` | one concrete copy of it | "this X here" |
| `formal` | the official version | "the X version" |

```
model      the transform, a construction, a schema, a pattern
token      a copy, a print, an impression, a specimen
formal     the declaration, the resolution, the ordinance
```

## The complete set

**132 answers in fifteen groups.** The five questions above cover the
99 that make a thing. Three more cover the kinds that make a feature, an
action or a manner, which are the same slot doing the same job in a
different word class.

The kinds that make a FEATURE:

The kinds that make an ACTION or a MANNER:

```
do        make  undo  again  become  give  take  put  seek

```

**`life` is the group a survey of English endings never finds**, because
English carries it as unrelated roots rather than as a suffix. `cub`,
`calf`, `kitten` and `piglet` are one kind applied to four roots, and
nothing in the words says so. The same holds for `nest`, `den`, `hive`
and `burrow`, and for `bark`, `moo`, `chirp` and `roar`. Any vocabulary
that only mines suffixes will miss all three.

**`standing` is the other one**, because English carries it in separate
words rather than endings. A right, a duty, a ban and a debt are all the
same slot filled differently, and all four attach to any action.

## How to decide

Run the test sentences. A word that passes several tests really carries
several concepts, and the answer is to write several chains rather than
to pick one.

**The sharpest test is the plural.** A `process` resists a plural and
takes a duration. A `result`, `product` or `event` takes a plural and a
number.

```
the discussion took three hours          process, no plural
the discussions were filed               record, plural
```

**The second sharpest is the agent phrase.** A `process` or `act` keeps
the doer, a `product` or `result` drops it.

```
the translation of the text by Smith     act
the translation is on the table          product
```

**The third state is `unclear`, and it is not the same as an absent
answer.** A word nobody has read the tests against is unmarked. A word
that was read and came back genuinely ambiguous in context is
`unclear`. Collapsing those two is what makes a coded vocabulary
uncodeable twice.

## Rules

**One chain, one answer.** A chain that would need two answers is two
chains, and they get written separately.

**Write every reading a word really has.** `discussion` gets five
entries, not one. Which one a sentence means is settled by the chain
that was written, which is the point.

**Order by the tests, not by frequency.** The reading a corpus sees most
is not the reading the concept is built from. `act` usually comes first
because the others are derived from it.

**A base with no answer is not a concept yet.** If none of the 132 fit,
the missing one is worth naming before the chain is written, and it goes
in this list.

**`unclear` is an answer.** Distinct from an unmarked word. See the
decision section above.

## What this changes

**The derived catalogue is one reading deep and needs to be several.**
[`derived/`](derived/readme.md) records 43,026 chains and 89 of them
carry more than one reading, because MorphyNet supplies one morpheme per
pair and the rule table maps each morpheme to one concept. Adding the
readings above is hand work, and the collapse map says where it pays:
the fourteen endings in that table cover most of the corpus.

**Three mappings in the rule table are now known to be too narrow.**

```
-hood   mapped to period    right for motherhood, wrong for neighborhood
-ery    mapped to practice  right for robbery, wrong for machinery
-osis   mapped to disease   right for tuberculosis, wrong for metamorphosis
```

**Most of this list has no morpheme to find it by.** The generated
catalogue reaches 72 concepts. The `life` group, the `standing` group,
the whole of `part`, and `target`, `source`, `goal`, `cause`, `chance`,
`habit`, `attempt`, `token` and `formal` besides, are carried by endings
that also carry something else or by no ending at all. They come from
the tests, or they do not come.
