# Thirty six

**No vowel pattern yet.**

The second of two sizes with a file and no path. Like
[twenty four](24.md), it probably does not want one, and this file
records why.

## What a thirty six could be

```text
36 = 6 x 6       the six squared
36 = 12 x 3      the twelve, three times
36 = 9 x 4       the nine, four times
36 = 4 x 9       around the cross, nine times
```

**Six squared is the interesting reading.** Thirty six is the first
square of a highly composite number, and if a thirty six is really a
`6 × 6` grid then the [six](6.md) path run six times says so.

Anything else at this size is a number and a smaller system compounded,
which needs no path at all.

## The abstract thirty six

> **ten digits and twenty six letters**

```text
0-9  and  A-Z  =  36
```

That is base 36, and it is the only reason thirty six is a recognised
size in computing. It is not a fact about the world: it is a fact about
the Latin alphabet, which is a fact about Rome.

**So the headline thirty six is conventional twice over.** Ten is
anatomy, twenty six is history, and their sum is neither.

## Fundamental

| domain | the thirty six | why it is clean |
| :--- | :--- | :--- |
| `6 × 6` | two dice, or a six by six grid | the square of the first useful composite |
| divisibility | 2, 3, 4, 6, 9, 12, 18 | seven proper divisors above one |
| sums on two dice | thirty six equally likely outcomes | the basis of most dice probability |
| a magic square of order 6 | thirty six cells, and no perfect solution | a real and surprising fact |

**The two dice thirty six is the strongest**, and it is the same fact as
`6 × 6`. Thirty six is what you get when two independent sixes meet, and
that is where every intuition about probability starts.

**There is no physical thirty six.** No geometry lands on it, no
particle count, no packing number. Compare [twelve](12.md), which is how
spheres pack, or [sixteen](16.md), which is four bits. Thirty six has
divisibility and nothing else.

## Advice

**Thirty six should not be a system in Tune.**

Every set at this size is either a grid, which is two smaller systems
crossed and should be said that way, or a numbered list, which the
[sixteen](16.md) numbers already handle.

Giving it a vowel path would mean tracing the cross nine times, and by
then the pattern carries no information: a listener cannot count nine
repetitions by ear, which is the whole thing a pattern is for.

**The practical limit is probably sixteen.** Past that, a path stops
being hearable, and a set should be built by compounding rather than by
extending. That limit is worth stating as a rule rather than discovering
one size at a time.

## Where the limit actually falls

| size | can a listener hear the position | |
| ---: | :--- | :--- |
| 2 to 5 | yes, the path is one pass | comfortable |
| 6 to 10 | yes, one fold or one star | workable |
| 12 | probably, four groups of three | at the edge |
| 16 | four rotations, if the rotation is fixed | at the edge |
| 24, 36 | no | compound instead |

**Worth testing rather than assumed.** If someone can reliably name the
position of a member in a twelve by its vowel alone, the limit is higher
than this guesses.
