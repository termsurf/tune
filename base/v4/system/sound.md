# What each sound means

Carried over from `make/v3.2/sounds.md`. This is the sense behind the
inventory: not what each sound is made with, which
[`../../../make/v4/readme.md`](../../../make/v4/readme.md) has, but what
each one is **for**.

Every word built to a pattern should agree with this. A word whose
sounds say the opposite of its meaning is worse than an arbitrary one,
because it actively misleads.

## The system is a body

> the system is not just a set of sounds
>
> it is a field, a body, a process, a cube of positions, a snake that
> weaves through them, and a human form that emerges from that weaving

There are 27 sounds and 27 positions in a cube, so each sound occupies
a place in a total structure rather than being arbitrary.

| part | sounds | what it does |
| :--- | :--- | :--- |
| head | `i e a o u` | perception |
| torso | `m n q` `g d b` `p t k` | creation |
| waist | `h` | life, the pivot |
| legs | `s z v f` `x j c C` | movement through existence |
| feet | `w l r y` | action in the world |

## The head: the vowels

```text
      i
   e  a  o
      u
```

| | |
| :--- | :--- |
| `i` | high, above, sharp, bright, active, sun |
| `e` | clear, defined, shaped, visible |
| `a` | level, present, grounded, earth |
| `o` | full, whole, enveloping, surrounding |
| `u` | low, inner, deep, hidden, moon |

Read as a run it is the layering of awareness:

```text
i  ->  e  ->  a  ->  o  ->  u
above  defined  present  whole  within
```

The three-way readings, which is what a size three set uses:

| | `i` | `a` | `u` |
| :--- | :--- | :--- | :--- |
| height | high | level | low |
| depth | out | surface | inner |
| light | bright | | dark |
| heat | hot | warm | cold |
| sky | sun | earth | moon |

**This is why white takes `i` and black takes `u`.** Any set running
bright to dark, hot to cold, or outer to inner should be ordered so the
vowel agrees with the sense.

## The torso: orientation, creation, abstraction

### `m n q` — the orientation of being

| | |
| :--- | :--- |
| `m` | positive, attraction, nourishment, belonging. Mom, pleasure, home, a good place. The sound humans make for *mmm* |
| `n` | negative, rejection, separation, boundary. Pain, alone. No, none, never, not |
| `q` | the hum, the field, the continuous underlying existence. Peace, harmony, flow, the satisfaction of nourishment |

```text
m = yes        n = no        q = ongoing
```

A spectrum, and that is why `man` could be **mind**: the full sweep
from positive through level to negative.

### `g d b` — creation becoming real

| | |
| :--- | :--- |
| `g` | the first explosive sound, the creative force, the first pulse of voice, the beginning of manifestation |
| `d` | the shaping, the tongue forming structure, the articulation of creation |
| `b` | the release, the opening into the world, the manifestation of form |

```text
g = creation impulse     d = formation     b = manifestation
```

### `p t k` — the abstract made real

| | |
| :--- | :--- |
| `p` | the pluck, the abstraction of action, the conceptual modelling of doing |
| `t` | the logic, the step, the structure, the rule, the equation |
| `k` | the implementation, the strike, the shaping of reality, the making of knowledge into form. The sound of rock chipping, bouncing off a flat surface. Okay, things are good |

```text
p = abstract action     t = structured logic     k = real execution
```

So the torso runs **orientation, creation, abstraction, realisation**.

## The waist: `h`

Breath. Life force. The spirit entering form, the transition from idea
into living existence.

This is the pivot, where the upper meets the lower.

## The legs: the snake, a double wave

```text
s  z  v  f        x  j  c  C
```

| | |
| :--- | :--- |
| `s` | sleep, snake, rest, the body at stillness. The skin, the covering, the outer layer of life |
| `z` | the ground, the substrate, the hum beneath. The land upon which things exist |
| `v` | vibration, energy, the base oscillation of being, the felt tone of existence |
| `f` | flow of force, movement of energy through the system, the breath outside the self, integration into the mesh |
| `x` | hush, quiet, subtle observation. Awareness without interference, the field seen softly. Rain, the silence of observing nature |
| `j` | soft shaping, inner forming, the quiet moulding of patterns from within, intention slowly becoming structure |
| `c` | thought, the forming of inner concepts, the structures of mind. That which can obscure direct realisation, the veil of thinking over the raw field |
| `C` | relation. The father, the mother, the brother, the sister. Connection to all things, the web of being, the recognition of self in other |

```text
rest -> ground -> energy -> motion -> awareness -> shaping -> thinking -> relation
```

**`c` and `C` are a polarity in the tail.** Thought can obscure;
relation can reveal.

## The feet: `w l r y`

The final contact with the world.

| | |
| :--- | :--- |
| `w` | wave, environment, being carried by the world, the motion of the surrounding field |
| `l` | line, path, connection, continuity through space |
| `r` | rise, roll, turn. Directed motion, movement with intention, progression |
| `y` | self, will, intention, the chooser, the inner direction |

```text
w = world     l = path     r = motion     y = will
```

This is locomotion, action, the rattle of the snake.

**The compass words are built on this row.** `web` west, `lut` south,
`rog` east, `yin` north, reading the feet left to right.

## So a word is a motion

```text
C1  =  origin / orientation
V   =  level / perception
C2  =  realization / manifestation
```

A root is **origin plus level plus becoming**.

| word | | |
| :--- | :--- | :--- |

> so the system is a cube, a body, a snake, a field, all at once
>
> and language becomes not arbitrary naming, but the tracing of
> position and motion through the structure of existence

## Two things to reconcile

**The torso order differs between documents.** This file gives
`m n q` / `g d b` / `p t k`. The layout in
[`../../../make/v4/readme.md`](../../../make/v4/readme.md) gives
`m n q` / `b d g` / `p t k`, left to right by place in the mouth.

Those are the same three sounds in opposite order. The layout is by
place, lips to back. This file is by process, impulse to manifestation.
Both are meaningful and they run opposite ways, so **say which one a
table is in.**

**`qan` is not a v4 word.** Checked against `base/v4/full/cvc.csv`:

```text
mak  nis  mux  vol  ric  raC  man     legal
qan                                   not legal
```

`q` cannot open a word in v4, which is the oldest rule the language
has and the one thing every version of it has agreed on. So the
field-mark example needs another word, and `q` can only ever do this
work from the end of a word or from inside a cluster.

That is worth knowing generally: **`q` means the field and the ongoing
hum, and it can only say so at a word's close.** Any system wanting `q`
to carry its sense at the front has to find another way.
