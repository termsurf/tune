<h3 align='center'>make</h3>
<p align='center'>
  How each Tune was built
</p>

<br/>

| | shapes | what it is for |
| :--- | :--- | :--- |
| [v3](v3) | `CVC` `CVCV C` `CVCVCVC` | alternating the whole way, no cluster anywhere |
| [v4](v4) | `CVC` `CVCC` `CCVC` | one syllable, one cluster, on one side of the vowel |

**v3 has two forms.** [rock](v3/rock) is the older one with nine
sounds, built for chant and song. [talk](v3/talk) is what it became,
with twenty seven.

**v4 keeps v3's sounds and v3's cluster lists** and spends them on one
syllable instead of three. It writes to `base/v4/`.
